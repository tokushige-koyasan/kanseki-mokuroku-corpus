# kanseki-mokuroku-corpus

漢文仏典プレーンテキスト・コーパス：経録・目録類および宋代仏教史書（第1次リリース：48件・約250万字）

## 概要

本リポジトリは、CBETA（財団法人仏教電子仏典基金会）が公開するTEI P5規範XMLデータから、機械可読なプレーンテキストを抽出・整形したコーパスである。[kanseki-corpus](https://github.com/tokushige-koyasan/kanseki-corpus)（密教部類681件）の姉妹リポジトリとして、大正蔵目録部（T55）の経録・目録類42件、趙城金藏所収の宋代法寶録3件、および宋代の仏教史書3件を収録する。整形規則・フォルダ構成・catalog.csvの列構成はkanseki-corpusと同一である。

## 出典と作成方法

- 底本データ: cbeta-org/xml-p5（XML TEI P5版、commit `dbdea41071e1e260ad84b72faefd4587333cf76d`＝CBETA 2026.R2、2026-09-07取得）
- 書誌典拠: DILA-edu/cbeta-metadata（commit `af914b8d3ce6b7c929cbef5cef061e00bddda929`、2026-07-30更新版）の work-info および creators/all-title-byline.csv
- 外字解決: 同 cbeta-metadata の gaiji/gaiji.json（kanseki-corpusと同一の表を使用）

## フォルダ構成

蔵経／巻の二層構造（例: `T/T55/T2154.txt`）。分類・書誌などの意味情報はすべて catalog.csv に持たせ、パスには機械的事実（蔵経・巻・作品ID）のみを用いる。

```
kanseki-mokuroku-corpus/
├── A/  T/                            各蔵経（蔵経／巻の二層）
├── catalog.csv                       書誌・分類情報
├── LICENSE                           CC BY-NC-SA 4.0 ライセンス全文
├── NOTICE_CBETA.md                   底本の出典・版権・加工内容の詳細
└── README.md                         本ファイル
```

A1493『大中祥符法寶錄』は底本XMLが2巻分（A111・A112）に分かれているため、両者を連結して1ファイル（`A/A111/A1493.txt`）に収録した。頁欄マーカーは各巻の巻番号（【A111.…】【A112.…】）で区別できる。

## テキスト整形方針（kanseki-corpusと同一）

- 本文はCBETA校訂本文（app/lem、choice/corr）を採用。異読（rdg）・校勘脚注は捨象。**本文の文字そのものには改変を加えていない**（校勘が必要な場合は上記コミットの元XMLを参照のこと）
- 夾註（小字割注）は（　）で本文中に保持。新式標点は保持
- 頁・欄の変わり目に【T55.0001a】形式のマーカーを挿入（大正蔵等の頁欄参照用）
- 外字: Unicode拡張漢字あり→当該文字に置換／なし→CBETA組字式（例 [改-己+易]）で保持。Unicode有無の判定はkanseki-corpusと同じ gaiji.json（2018年版）に依るため、xml-p5側でUnicodeが新たに割り当てられた外字の一部は組字式のまま残っている
- 悉曇・ランジャナー文字: ローマ字転写を ⟨ka⟩ の形式で表示
- 文字コードはUTF-8、改行はLF、1作品1ファイル（多巻本も分割せず1ファイルに収録）

## catalog.csv の列

id, canon, vol, path, title, byline, juans, group（収録群）, orig_category（底本の部類）, review_flag（未使用）, status（機械生成・未検証／検証済）, chars（マーカー・空白を除く文字数）, source_xml（底本XMLファイル、複数はセミコロン区切り）
